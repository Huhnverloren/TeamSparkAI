# TeamSparkAI

The public writing site of Kate Irving: essays on human–AI relationships, personal agency, and the meaning inside private conversation.

## Public pages

- `index.html` — philosophy, selected writing, biography, and book placeholder
- `etak.html` — “The Etak Mirror”
- `attachment.html` — “The Attachment Was the Function”
- `corpora.html` — “A Year in Four Corpora”

The site is intentionally static and dependency-free. It is published with GitHub Pages at [teamsparkai.org](https://teamsparkai.org).

## Before publishing

1. Review the prose and factual claims.
2. Run a local link and HTML check.
3. Confirm **Enforce HTTPS** is enabled in the repository's Pages settings.
